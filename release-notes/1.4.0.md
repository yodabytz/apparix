# Apparix 1.4.0

- Installed plugins now appear in Admin > Updates when a newer purchased version is available.
- Download and install eligible plugin updates with one click, preserving settings and activation.
- Plugin downloads verify purchase eligibility, package identity, version, and SHA-256 integrity.
- Updates validate PHP and archive paths, stage files before replacement, and retain rollback backups.
- Independently installed plugins are protected from core update file replacement.
- The Updates sidebar badge includes available plugin updates.

Install this Apparix core update first to enable plugin updates. Plugin installations remain administrator-initiated.
